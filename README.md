# Landing Page - Atividades de Gêneros Textuais

Site estático pronto para deploy.

## Deploy na Vercel

1. Suba esta pasta para um repositório no GitHub.
2. Em vercel.com → **Add New Project** → importe o repositório.
3. Configurações:
   - **Framework Preset:** Other
   - **Build Command:** (deixe vazio)
   - **Output Directory:** `.` (ponto)
   - **Install Command:** (deixe vazio)
4. Clique em **Deploy**. Pronto.

## Conteúdo
- `index.html` — página renderizada (com Meta Pixel 989992396912663 e Utmify embutidos)
- `assets/` — JS, CSS e imagem do mockup
- `vercel.json` — configuração de URLs limpas
