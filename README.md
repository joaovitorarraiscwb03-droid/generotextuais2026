# Static Export — Atividades de Gêneros Textuais

Pasta pronta para deploy no GitHub + Vercel.

## Conteúdo
- `index.html` — página única com tudo (HTML + Tailwind via CDN + JS)
- `assets/` — todas as imagens
- `vercel.json` — configuração para deploy estático

## Deploy

### GitHub
1. Crie um repositório novo no GitHub
2. Faça upload de todos os arquivos desta pasta para a raiz do repositório

### Vercel
1. Acesse https://vercel.com/new
2. Importe o repositório do GitHub
3. Framework preset: **Other** (deixe tudo padrão)
4. Output directory: `./` (raiz)
5. Clique em **Deploy**
